Tabbed switcher between sibling views.

```jsx
<Tabs defaultValue="holding">
  <TabsList>
    <TabsTrigger value="holding">Holding</TabsTrigger>
    <TabsTrigger value="ledger">Ledger</TabsTrigger>
  </TabsList>
  <TabsContent value="holding">…</TabsContent>
  <TabsContent value="ledger">…</TabsContent>
</Tabs>
```
